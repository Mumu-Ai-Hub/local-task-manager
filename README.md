# 本地任务管理应用

零依赖的本地任务管理工具：月视图、周视图、To-dos、月度/年度目标、到点提醒，数据全部存在浏览器本地。

不需要构建、不需要后端、不联网上传任何数据。双击 `index.html` 就能用。

## 快速开始

```powershell
# 以应用窗口方式打开（本机 127.0.0.1:41730 静态服务）
.\Start-TaskManager.ps1
```

或直接双击 `index.html`。

## 安装为桌面应用

```powershell
.\install.ps1
```

在桌面和开始菜单创建快捷方式，指向同一份本地文件。

## 功能

- 月视图 / 周视图切换，日历格与 To-dos 双向同步
- 任务属性：日期、时间、颜色、优先级、备注、完成状态
- 本月目标与本年目标
- 到点提醒：系统通知 + 应用内提示 + 声音，可稍后 10 分钟或直接完成
- JSON 导出 / 导入，用来备份和迁移

## 数据与隐私

任务数据保存在当前浏览器的 `localStorage` 中，不会上传到任何服务器。换浏览器或换电脑时需要先导出 JSON 再导入。

系统通知需要在页面右侧点击「开启提醒」并授权浏览器通知权限。

## 已知限制

- 提醒只在应用窗口打开时触发，关闭页面后不会有后台提醒（没有 Service Worker 推送）
- 单浏览器单设备，不支持多人协作和跨设备同步
- 清除浏览器站点数据会一并清空任务，请定期用 JSON 导出备份

## 技术构成

纯静态：`index.html` + `styles.css` + `app.js`，加一份 PWA manifest 和 `sw.js`。`sw.js` 只预缓存这几个本地文件，未命中时原样放行同目录请求；`app.js` 和 `index.html` 里没有任何外部域名请求，也没有埋点。
